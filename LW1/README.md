# Лабораторная №1 — вариант 2: правильный октаэдр

C++17, Vulkan, GLFW, Dear ImGui, GLM. Реализованы основной вариант и все 6 дополнительных заданий из `CG Lab #1.pdf`.

## Сборка и запуск (Ubuntu 24.04)

```bash
sudo apt-get update
sudo apt-get install build-essential cmake ninja-build pkg-config libvulkan-dev libglfw3-dev libglm-dev libimgui-dev glslang-tools
cmake -S . -B build -G Ninja
cmake --build build
./build/octahedron
```

Необходимы графическая сессия и драйвер Vulkan. Для программного рендеринга можно установить `mesa-vulkan-drivers`. Проверенная версия Dear ImGui — **1.90.1** (пакет Ubuntu 24.04); API Vulkan backend у других версий может отличаться. Исходники backend должны соответствовать версии библиотеки. При нестандартной установке укажите `-DIMGUI_BACKENDS_DIR=/путь/к/imgui/backends` и `CMAKE_PREFIX_PATH`.

Шейдеры компилируются автоматически. Программа ищет SPIR-V в каталоге сборки, поэтому её можно запускать из любого рабочего каталога. При переносе проекта пересоберите его.

## Управление

Панель слева управляет сценой в реальном времени. Подписи интерфейса английские, пояснения ниже:

- **Perspective** — перспективная / ортографическая проекция. FOV и Ortho half-height регулируют угол обзора и размер ортографического объёма.
- **Distance, Yaw, Pitch** — расстояние и углы камеры, направленной на начало координат.
- **Objects** — от одного до трёх октаэдров; **Selected** выбирает объект для редактирования.
- **Position, Rotation, Scale** — перенос, поворот в градусах и масштаб по каждой оси. Неравномерный масштаб деформирует исходный правильный октаэдр.
- **Tint** — цвет объекта; **Procedural vertex colors** включает умножение этого цвета на цвета вершин.
- **Animate selected object** — движение по пространственной восьмёрке и вращение по трём осям.
- **Pause all / Play all** — пауза / продолжение анимации. **Speed, Radius, Height, Phase** задают параметры траектории выбранного объекта.
- **Restart selected** — сброс времени анимации; **Reset selected object** — восстановление параметров объекта.
- **Visible** — видимость выбранного объекта; **Esc** — выход.

По умолчанию показан один неподвижный октаэдр. Команда `./build/octahedron --demo` показывает три анимированных объекта.

## Проверки

```bash
ctest --test-dir build --output-on-failure
./build/octahedron --smoke-test
```

Тест геометрии проверяет равенство рёбер, замкнутость сетки и внешний обход граней. Smoke test за 120 кадров показывает три объекта, переключает проекцию, изменяет размер окна, ставит анимацию на паузу и продолжает её. Он требует графической сессии.

Для диагностики Vulkan:

```bash
sudo apt-get install vulkan-validationlayers
VK_INSTANCE_LAYERS=VK_LAYER_KHRONOS_validation ./build/octahedron --smoke-test
```

`--frames N` автоматически завершает программу после N кадров. Это полезно для проверки запуска; значение 0 означает обычный режим без ограничения.

## Файлы

- `src/main.cpp` — Vulkan, буфер глубины, дескрипторы, интерфейс, матрицы и анимация.
- `src/geometry.hpp` — 6 вершин и 24 индекса восьми треугольников.
- `shaders/octahedron.vert`, `shaders/octahedron.frag` — преобразование координат и цвет.
- `tests/geometry.cpp` — проверка правильного октаэдра.
- `docs/report.md` — математическое описание и соответствие заданию.
